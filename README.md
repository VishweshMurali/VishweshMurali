## 👋 What you'll find here

This profile is a working lab for **LLM-powered applications**: retrieval, agents, human review loops, and the evaluation harnesses that keep them honest. Most projects run locally, ship with tests, and document what they *don't* do.

## 🚀 Featured projects

| Project | What it does | Highlights |
|---|---|---|
| **[SkillMapper](https://github.com/VishweshMurali/skillmapper)** | Agentic RAG that scores a resume against a job description and escalates low-confidence cases to a human | Hybrid BM25 + dense retrieval (hand-written RRF) · LangGraph agent **and** a 5-server MCP design · RAGAS-evaluated chunking fix · 75 tests · fully local on Ollama |
| **[HILT](https://github.com/VishweshMurali/hilt)** | Human-in-the-loop invoice verification: an LLM extracts, deterministic rules decide, a reviewer resolves escalations | Red-teamed against prompt injection · source-text grounding · duplicate detection · 48-case labeled eval (8 adversarial) · LangGraph `interrupt()` + Streamlit reviewer |
| **[InterviewPrep](https://github.com/VishweshMurali/InterviewPrep)** | Adaptive interview tutor built from your own notes, resume, and a target job description | Multi-judge LLM scoring with disagreement flags · adaptive difficulty · concept knowledge graph · FastAPI + Streamlit |
| **[Insightify](https://github.com/VishweshMurali/Insightify)** | Multilingual review-sentiment dashboard for scraped or uploaded product reviews | Language detection + per-language models · aspect extraction · trends and word clouds |

## 🧭 How I build

- **Measure before claiming.** Benchmarks get reported even when unflattering (one optimization gave no speedup, and the README says so).
- **Attack my own systems.** Adversarial and prompt-injection cases sit next to the happy path.
- **Human in the loop** where a wrong answer is costly, with escalations that explain *why*.
- **Document the limits.** Every repo has a *Limitations* section.
